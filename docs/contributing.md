# Contributing

fSTG Toolkit is developed openly on
[GitHub](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit). Bug reports, feature ideas,
documentation fixes and code contributions are all welcome.

## Ask a question

For questions about using the toolkit, start with this documentation and with the built-in help
(`python -m fstg_toolkit --help`, or `--help` on any subcommand). If that is not enough, ask in
the **Q&A** category of the
[discussions](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit/discussions), so that the answer
stays searchable for the next person.

## Report a bug

Open an issue with the
[bug report form](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit/issues/new/choose), after
searching the [existing issues](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit/issues). The form
asks for the version (`python -m fstg_toolkit --version`), your Python version and operating
system, the installed extras, and a minimal reproducible example; please fill them in, as they
are usually what makes a bug fixable.

## Contribute code or documentation

The full guide lives in
[CONTRIBUTING.md](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit/blob/main/CONTRIBUTING.md): it
covers the development setup, how to run the unit tests and the doctests, the code style, the
CeCILL-2.1 license header required on new files, the commit message convention, and the pull
request process.

Everyone taking part in the project is expected to follow the
[Code of Conduct](https://github.com/ICube-Medical-Image-Computing/fstg_toolkit/blob/main/CODE_OF_CONDUCT.md).
